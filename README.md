# To-Do List

Консольный менеджер задач на Python.

## Возможности

- Добавление, показ, отметка выполненной и удаление задач
- Сохранение в JSON-файл (данные переживают перезапуск)
- Валидация ввода (не падает на `abc` и пустых строках)
- Автоматическая генерация id

## Как запустить

```bash
python todo.py
